# A table to convert the pollen taxa identified by investigators to standardized lists.

A list of standardized (published) taxonomies from the literature to
help standardize taxonomies for synthesis work.

## Usage

``` r
data(pollen.equiv)
```

## Format

a `data.frame` object

## Details

Taxon conversion table (readable).
