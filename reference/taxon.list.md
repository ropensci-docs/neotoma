# Neotoma taxon list

The taxonomy table for datasets in neotoma, as would be returned by
[`get_table`](https://docs.ropensci.org/neotoma/reference/get_table.md)

## Usage

``` r
data(taxon.list)
```

## Format

a `data.frame` object

## Source

The Neotoma database.
